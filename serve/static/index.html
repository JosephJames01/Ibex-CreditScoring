Opens TrueLayer’s secure sign-in. Choose Mock Bank in the sandbox to log in with test credentials. Your bank data is reconstructed into the same features used to train the model — no credentials are stored here.

One-time setup to enable the live connection

  1. Create a sandbox app at console.truelayer.com and copy its client_id / client_secret.
  2. Add the redirect URI http://localhost:8000/callback to that app.
  3. Set them before launching the server, then restart:
    $env:TRUELAYER_CLIENT_ID="…"
    $env:TRUELAYER_CLIENT_SECRET="…"
